# 오프라인 교통안전 음성 질문지

교수 PC 한 대에서 실행하고, 같은 Wi-Fi에 연결된 교육생 기기가 브라우저로 접속하는 프로그램입니다. 응답은 외부로 전송하지 않고 교수 PC의 `data/results.db`에 저장합니다.

인터넷에 공개하여 운영할 수도 있습니다. 배포용 `Dockerfile`과 보안·영구저장 설정은 `INTERNET_DEPLOY.md`를 확인하십시오. 실제 공개 주소는 별도의 웹 호스팅 서버에 배포한 뒤 발급됩니다.

`data/questions.json`은 제공된 `질문지3페이지.pdf`의 3쪽을 페이지 이미지와 대조하여 입력했습니다. Q1 19문항과 Q2 30문항이 들어 있으며, Q2의 10·15·20·26·29번은 원본 표의 `⑤④③②①` 표기에 따라 역채점합니다. 검사 도구의 공식 하위척도 산식이나 해석 기준은 첨부 PDF에 없으므로, 현재 관리자 화면은 전체 점수와 문항별 통계만 제공합니다.

## 가장 쉬운 설치 방법 (Windows)

### 인터넷이 연결된 준비용 PC

1. Python 3.11 이상을 설치합니다. 설치 화면에서 **Add Python to PATH**를 선택합니다.
2. 이 폴더에서 `prepare_offline.bat`를 두 번 클릭합니다.
3. 생성된 `offline_packages` 폴더를 포함하여 `traffic_safety_quiz` 폴더 전체를 USB에 복사합니다.

### 인터넷이 없는 교육장 강사 PC

1. Python 3.11 이상 설치 파일도 USB로 가져와 먼저 설치합니다.
2. 폴더 전체를 강사 PC에 복사합니다.
3. `install.bat`를 한 번 실행합니다.
4. 이후에는 `run.bat`만 실행합니다.
5. 검은 창에 표시되는 `http://192.168.x.x:5000` 주소를 교육생에게 안내합니다.
6. 모든 기기를 같은 Wi-Fi 공유기에 연결합니다. 인터넷 연결은 필요하지 않습니다.

Windows 방화벽 질문이 나타나면 **개인 네트워크** 접근을 허용합니다. 서버 창을 닫으면 프로그램이 종료됩니다.

## 화면 사용법

- 교육생: 첫 화면에서 본인의 좌석 번호를 입력한 뒤, 왼쪽 Q1 또는 오른쪽 Q2 큰 버튼을 눌러 검사를 시작합니다.
- 교육생은 교육장마다 다른 QR코드 또는 숫자로만 구성된 6자리 접속코드로 입장합니다. 기본 주소에서는 검사방을 임의로 선택할 수 없어 동시간대 여러 교육장의 결과가 섞이지 않습니다.
- 질문 화면: `답안 모두 듣기`를 누르면 ① 전혀 그렇지 않다부터 ⑤ 매우 그렇다까지 차례대로 음성으로 안내합니다.
- Q1 완료: 원본 표의 흰색 가·나·다 칸에 따라 `잘못된 손익계산`, `운전능력 과신`, `죄책감` 점수를 각각 합산하여 완료 화면 오른쪽 아래에 표시합니다.
- Q2 완료: 원본 표의 흰색 라·마·바·사·아·자 칸과 역채점 표시를 반영하여 `도덕성`, `내부귀인`, `외부귀인`, `자기통제력`, `충동성`, `감각추구성향` 점수를 각각 표시합니다.
- 강사: 첫 화면 아래의 **강사 관리자 화면**을 누릅니다.
- 관리자에서 교육장·날짜·반별로 새 강의방을 만들면 고유 접속주소와 QR코드가 생성됩니다. 해당 QR로 접속한 결과는 그 강의방에만 저장됩니다.
- 강의방을 개설할 때 방별 관리자 번호를 지정합니다. 방 관리자는 로그인 화면에서 강의방 코드와 관리자 번호를 입력하면 자기 방의 결과만 볼 수 있습니다. 총괄 관리자는 강의방 코드를 비우고 기본 PIN으로 로그인합니다.
- 관리자 로그인 화면에서는 코드를 직접 입력하지 않고 개설된 교육장을 목록에서 선택합니다. `교육장 설정`에서 방별 관리자 번호를 변경할 수 있습니다.
- 강의방별 참여 현황에서 전체 참여 인원, 완료 인원, 진행 중 인원과 완료율을 확인합니다. 답안 번호별 인기 분포는 표시하지 않습니다.
- 선택한 강의방의 QR 미리보기를 누르면 교육생에게 보여줄 대형 QR 화면이 열리며, 이미지 저장과 인쇄를 지원합니다.
- 결과 삭제는 개별 검사 삭제, 선택한 강의방 결과 전체 삭제, 강의방과 결과 함께 삭제의 세 가지 방식으로 제공합니다.
- 초기 관리자 PIN: `1234`
- 결과: 관리자 화면에서 목록·완료율·문항별 평균·선택지별 인원을 확인하고 CSV 또는 Excel로 내려받습니다.

## 관리자 PIN 변경

명령 프롬프트에서 다음처럼 실행하면 해당 실행에 새 PIN이 적용됩니다.

```bat
set ADMIN_PIN=원하는번호
run.bat
```

운영 전에는 반드시 기본 PIN을 변경하십시오.

## 음성 기능

1. 교육생 기기의 한국어 브라우저 음성을 먼저 사용합니다.
2. 사용할 수 없으면 강사 PC의 Windows 오프라인 음성으로 WAV 파일을 만들어 재생합니다.
3. 강사 PC의 Windows 설정에서 한국어 음성 패키지가 설치되어 있어야 자연스러운 한국어가 나옵니다.
4. 음성이 실패해도 질문과 응답 기능은 계속 작동하며 화면 안내가 표시됩니다.

브라우저마다 음성 지원 방식이 다르므로 실제 교육에 사용할 태블릿에서 Wi-Fi의 인터넷 연결을 끈 상태로 미리 시험하십시오.

## 질문 데이터 교체

질문은 `data/questions.json`에 코드와 분리되어 있습니다. PDF를 받으면 다음 항목을 원문 그대로 입력합니다.

- 검사 ID와 검사명
- 문항 ID, 원문 번호, 원문 질문
- 읽기 문장과 중립적인 도움말
- 선택지
- 역채점 여부와 점수 정보

JSON 문법 오류가 있으면 서버가 시작되지 않습니다. 수정 전 파일을 복사해 두고, 편집 후 아래 검사를 실행하십시오.

```bat
.venv\Scripts\python.exe -m json.tool data\questions.json > nul
```

## 데이터 보관과 백업

- 데이터 파일: `data/results.db`
- 프로그램 종료 뒤에도 유지됩니다.
- 백업할 때는 서버 창을 닫고 `results.db`를 USB 등 안전한 위치에 복사합니다.
- 응답을 삭제하는 기능은 의도적으로 관리자 화면에 넣지 않았습니다.

## 자주 생기는 문제

- **다른 기기에서 접속 안 됨:** 같은 Wi-Fi인지, 서버 창이 열려 있는지, Windows 방화벽에서 개인 네트워크를 허용했는지 확인합니다.
- **음성이 안 나옴:** 기기 음량과 무음 모드, 브라우저의 자동 재생 허용 여부, Windows 한국어 음성 설치 상태를 확인합니다. 먼저 버튼을 한 번 눌러야 음성이 허용되는 기기도 있습니다.
- **설치 실패:** `offline_packages` 폴더가 있는지와 준비용 PC/교육장 PC의 Python 버전 및 Windows 종류(64비트)가 같은지 확인합니다.
- **500 오류:** `data/questions.json`의 쉼표·따옴표 오류와 서버 창의 오류 메시지를 확인합니다.

## 파일 역할

- `app.py`: 화면 제공, 응답 저장, 관리자 인증, 통계와 다운로드
- `data/questions.json`: 검사 및 질문 원문 데이터
- `data/results.db`: 자동 생성되는 SQLite 응답 데이터
- `templates/`: 각 화면 구조
- `static/css/style.css`: 큰 글씨와 터치용 화면 디자인
- `static/js/quiz.js`: 문항 이동, 선택, 필수 응답 처리
- `static/js/speech.js`: 브라우저/강사 PC 음성 처리
- `prepare_offline.bat`: 인터넷 PC에서 오프라인 설치 묶음 준비
- `install.bat`: 교육장 PC에서 설치
- `run.bat`: 서버 실행

## 운영 전 확인 목록

1. PDF 문항과 `questions.json`을 두 사람이 대조 검수합니다.
2. 역채점과 총점 계산 기준을 원본 채점 지침으로 확인합니다.
3. 관리자 PIN을 변경합니다.
4. 교육장에서 실제 공유기와 교육생 기기로 전 문항을 시험합니다.
5. 인터넷 연결을 끈 상태에서 음성과 저장을 시험합니다.
6. CSV/Excel 파일을 열어 한글과 점수가 맞는지 확인합니다.
